🚀 INSTALAÇÃO RÁPIDA (Windows)
================================================================================

1. Abra o PowerShell ou CMD como Administrador

2. Navegue até o diretório do projeto:
   cd C:\Users\Thinkin pad 8g\AgroVision-AI

3. Execute o script de setup:
   scripts\setup.bat

4. Ou faça manualmente:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python scripts\download_models.py
   copy .env.example .env

================================================================================

================================================================================
🎨 ANIMAÇÕES CSS DO DASHBOARD
================================================================================

O dashboard inclui animações CSS em tempo real:

1. Animais SVG se movendo (animal-walk)
2. Bounding boxes tracejadas animadas (bbox-dash)
3. Linha de scanning vertical (scan-move)
4. Indicador "Em Tempo Real" pulsando (pulse-live)
5. Gráficos de atividade animados (line-draw, bar-grow)
6. Loading spinner (spinner-rotate)
7. Transições suaves em todos elementos
